# موقع «جمعية حاضنة الجمعيات»

موقع ثابت (Static) عربي RTL، يُبنى من **مصدر واحد** عبر مولّد Python.

## البناء
```bash
python src/build.py
```
يقرأ المصدر من `src/` ويولّد الموقع كاملاً في `site/`.

## البنية
| المجلد | الوصف |
|---|---|
| `src/` | المصدر: `build.py` + `templates/` (رأس/قائمة/تذييل) + `content/` (محتوى كل صفحة) + `data/pages.json` + `static/` (اللوحة/404 + الأصول + `files/`) |
| `site/` | **الناتج المنشور** — لا تُعدّله يدويًا؛ يُعاد توليده من `src/` |
| `docs/` | تحليل النظم ودليل النشر |

> القاعدة: عدّل في `src/` ثم أعد البناء. لا تُعدّل ملفات `site/` مباشرةً.

## النشر
Cloudflare Pages — **مجلد الإخراج (Build output directory): `site`**، بلا أمر بناء.

## المكدّس
